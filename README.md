A make.fun entry for the **Fortune Cookie for the Liquidated Trader**
bounty: one fortune-cookie line for a crypto trader who has just been
liquidated — rueful, warm, and funny instead of cruel.

## The fortune

> You lost everything at 3am except your sense of humour — the cookie says that was the real leverage.

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single fortune line to `/output/entry.txt`
(UTF-8, 100 characters, 19 words — inside the 1–160 character gate and
the 20-word cap).

```sh
python3 main.py
cat /output/entry.txt
```
